# Playbook: 404 / empty state

**Refs:** `404s.design` · `drafthouse refs search 404`

## IA

```
code or short title (404)
what happened (one sentence)
one primary path back
optional: search or top 2 links
```

## Do
- Same type system as the rest of the product
- Calm tone; no jokes that age poorly
- CTA: “Back to the ledger” / “Go home”

## Don’t
- Blame the user
- Dead-end with no link
- Stock illustration that fights the brand

## Structure checks
`includes:404` or product-specific code, `has-cta`
