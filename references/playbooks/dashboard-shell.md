# Playbook: Dashboard shell

**Refs:** `refero-styles`, `linear-method` · `drafthouse refs search dashboard`

## IA

```
[sidebar nav | collapsible]
[top bar: breadcrumb / search / user]
[main: page title + primary action]
[content: tables or cards — not both fighting]
```

## Do
- Density: compact rows for data, generous padding for empty states
- One accent for primary actions
- Empty state explains next action

## Don’t
- Marketing gradients inside app chrome
- Chart junk without a job
- Hiding critical nav behind mystery icons only

## Token hooks
`--dt-paper`, `--dt-ink-2`, `--dt-rule`, `--dt-moss` for positive
