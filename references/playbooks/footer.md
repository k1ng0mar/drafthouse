# Playbook: Footer

**Refs:** `footer-design` · `drafthouse refs search footer`

## IA

```
brand + one-line purpose
link columns (Product / Docs / Company) — max 3–4 cols
legal row (©, privacy, terms) — quiet
```

## Do
- Hierarchy quieter than hero
- Same token palette as body
- Honest links only (no dead # if avoidable)

## Don’t
- Duplicate entire navbar
- Heavy illustration unless brand system requires it

## Structure checks
`has-footer`
