# Playbook: Docs sidebar

**Refs:** `stripe-docs-ui`, `developer-docs` system · `drafthouse refs search docs`

## IA

```
[sidebar: sections → pages] [main prose max ~72ch] [optional toc]
```

## Do
- Monospace for code; body for prose
- Persistent active state in sidebar
- Headings map to TOC

## Don’t
- Marketing hero on every docs page
- Body width > 80ch
- Low-contrast code blocks

## Structure checks
nav-like sidebar, `has-title`
