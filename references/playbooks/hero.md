# Playbook: Hero

**When:** landing pages, product marketing, campaign plates.  
**Refs:** `supahero`, `landing-love`, `lapa-ninja` · search `drafthouse refs search hero`

## IA (typical)

```
[eyebrow / kicker]
[H1 — offer or outcome, not the company name]
[1–2 sentences support]
[primary CTA] [secondary text link]
[optional proof strip — logo row OR one honest stat OR omit]
```

## Do
- One H1; largest type is the offer
- CTA above the fold on ~1366×768
- Support copy ≤ 2 lines
- Align to design-system tokens (`--dt-rust` for primary action)

## Don’t
- Purple gradients / emoji icons
- Invented metrics
- Three competing CTAs
- Inter/Roboto as display face

## Token hooks
`--dt-font-display`, `--dt-ink`, `--dt-rust`, `--dt-paper`

## Structure checks
`has-hero`, `has-h1`, `has-cta`, `no-lorem`
