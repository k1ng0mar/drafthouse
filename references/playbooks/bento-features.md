# Playbook: Bento / feature grid

**Refs:** `bentogrids`, `unsection` · `drafthouse refs search bento`

## IA

```
section H2 + short lede
grid of feature plates (2×2 / bento mix)
each plate: title + 1–2 lines + optional micro-visual
```

## Do
- Clear primary cell if one feature leads
- Consistent plate padding
- Real feature names (not “Feature One”)

## Don’t
- Every cell equal weight + equal noise
- Emoji per card
- Invented percentages

## Structure checks
feature titles specific to brief
