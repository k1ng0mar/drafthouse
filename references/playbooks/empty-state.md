# Playbook: Empty state

**Refs:** `404s.design` patterns · product-ui galleries

## IA

```
short title
why it’s empty (1 line)
primary action
optional secondary “learn more”
```

## Do
- Actionable copy
- Same tokens as populated state
- Skeleton only if load is real

## Don’t
- Shrug copy (“Nothing here!”)
- Dead illustration + no CTA
