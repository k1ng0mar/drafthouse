# Design reference library

Agent-facing catalog of **public design galleries** for pattern research.

```
references/
  catalog.json          # machine-readable (MCP / CLI)
  by-category/*.md      # human + agent notes
  README.md
```

## Principles

1. **Lookup before invent** — steal structure, not pixels.
2. **Token-first** — re-skin everything through `design-systems/*/tokens.css`.
3. **Lint after** — references never excuse purple gradients or emoji icons.
4. **Few URLs, deep structure** — 1–3 refs per pattern beat 20 open tabs.

## Full category list

See `catalog.json` → `categories`, or run `drafthouse refs list`.
