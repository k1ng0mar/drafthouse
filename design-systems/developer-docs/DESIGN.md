# Developer Docs

High-legibility documentation system — mono-forward, quiet chrome, code-first.

## Type
- Prose: system-ui / "Segoe UI"
- Headings: same, weight 600 (not novelty display)
- Code: "JetBrains Mono", "SF Mono", Consolas

## Color
- Background `#ffffff`, text `#0c0a09`
- Links `--dd-link` `#0f766e`
- Code bg `#f5f5f4` with border
- Sidebar muted `#57534e`

## Rules
- Measure 65–72ch
- Sidebar + content; optional right TOC
- No marketing gradients in docs chrome
