# Editorial Field

Warm parchment, ink type, restrained rust accent — long-form and field-manual plates.

## Direction
- Editorial research desk; hairline rules; numbered plates
- Display serif for H1–H3 only

## Type
- Display: Fraunces / Georgia, serif
- Body: IBM Plex Sans / system-ui
- Mono: DM Mono / Consolas

## Color rules
- Paper `--ed-paper`, ink `--ed-ink`
- Accent `--ed-rust` for primary action only
- No purple gradients; no emoji icons
