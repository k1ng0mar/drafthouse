# SaaS Minimal

Crisp neutral SaaS marketing — cool gray surfaces, single blue reserved for CTA only when brand allows; default uses ink + moss for Drafthouse-safe lint.

## Type
- Display: "Söhne", "Segoe UI", system-ui (not Inter as decorative display)
- Body: same stack, regular

## Color
- Page `#fafafa`, card `#ffffff`, ink `#111827`
- CTA `--sm-accent` = `#0f766e` (teal — avoids AI indigo/violet lint)
- Borders hairline `#e5e7eb`

## Rules
- Generous whitespace; max 2 CTAs per viewport
- Feature plates flat; no heavy shadows
- Pricing uses honest labels
