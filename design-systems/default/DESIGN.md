# Drafthouse Field — default design system

Neutral research-desk system for Drafthouse product UI and agent-generated plates.
Not a template look: ink field notes, parchment plane, moss/olive signals, rust for action.

## Direction

- **Register:** editorial technical fieldbook (sibling of FIELD//ENGINE)
- **Posture:** flat, architectural, low chrome; framed plates not soft cards
- **Accent discipline:** rust (`--dt-rust`) for primary action only; olive for signals/rules

## Type

| Role | Stack |
|------|--------|
| Display | Fraunces, Georgia, "Times New Roman", serif |
| Body | "IBM Plex Sans", "Avenir Next", "Segoe UI", system-ui, sans-serif |
| Mono | "DM Mono", "SF Mono", Consolas, monospace |

Display faces for H1–H3 and plate titles only. Never Inter/Roboto/Arial as display.

## Color rules

- Page: parchment `--dt-paper`
- Ink text: `--dt-ink` / `--dt-ink-2`
- Primary action: `--dt-rust`
- Signals/rules: `--dt-moss`, `--dt-olive`
- No purple/violet/indigo gradients
- No emoji feature icons

## Layout rules

- Prefer hairline rules + numbered plates over card grids
- Body measure ~65–72ch for reading surfaces
- Focus-visible ring uses olive
- Respect `prefers-reduced-motion`

## Copy rules

- Specific over clever; active voice
- No invented metrics; honest stubs (`—`) when data is missing
- No “Feature One” / lorem ipsum in ship artifacts
